# Sistema de Análise Comercial em Python
Projeto criado para mostrar como os fundamentos da linguagem Python podem ser usados para processar e analisar dados comerciais.
# Objetivo
O sistema pega informações sobre vendas e gastos e converte esses dados em indicadores básicos para ajudar na análise de negócios.
# Indicadores
- Número de vendas
- Receita total
- Venda mais alta
- Venda mais baixa
- Gastos
- Lucro
- Média por venda
- Margem de lucro
- Avaliação do desempenho
# Conceitos usados
- `def`
- `if`, `elif` e `else`
- `while`
- `while True`
- `for`
- `range`
- `input`
- `print`
- Variáveis
- Cálculos matemáticos
- `try/except`
- Uso de `return` para retornar valores de funções
- Tratamento e análise de dados
# Estrutura
Uma regra importante do projeto é separar a lógica das funções da parte que interage com o usuário.
As funções recebem dados como parâmetros e devolvem os resultados. As entradas (`input`) e as saídas (`print`) ficam no fluxo principal do programa.
# Como rodar
É preciso ter o Python 3 instalado.
No terminal:
python analise_comercial.py
